# 메타(Meta) 스타일 디자인 토큰

첨부 파일(`메타디자인.md`)에서 추출한 디자인 시스템을 수업용 슬라이드에 맞게 단순화했다.
원본은 정보밀도가 높은 리포트형이지만, 이 스킬은 **한 슬라이드 = 한 메시지** 원칙으로
고1 학생이 뒤에서도 읽을 수 있도록 폰트를 키우고 여백을 넉넉히 뒀다.

## 색상 토큰 (hex, `#` 없이 사용 — pptxgenjs 규칙)
```js
canvas  FFFFFF  // 배경(항상 흰색)
inkDeep 0A1317  // 제목
ink     1C1E21  // 본문
steel   5D6C7B  // 부제/캡션
stone   8595A4  // 페이지 번호
blue    0064E0  // 포인트 컬러(챕터 라벨, 불릿, 강조 카드) — 유일한 강조색
lblue   CFE0FB  // 표지 eyebrow 배지 배경
soft    F1F4F7  // 카드 배경(진함)
softer  F8FAFD  // 카드 배경(연함), 이미지 자리
border  DEE3E9  // 헤어라인 테두리
yellow  F7B928  // 예비 강조색(과용 금지)
```

## 규칙
- 배경은 항상 흰색. 색은 **blue 한 가지만 포인트로** 쓴다(희소성 원칙 — 여러 색을 섞지 않는다).
- 카드/박스는 흰색 또는 `soft`/`softer` 배경 + 헤어라인 테두리(`border`, 1pt) + 둥근 모서리(radius 0.14in).
- 폰트: `Pretendard`(미설치 환경이면 시스템 고딕으로 자동 대체됨).
- 헤더 패턴: 챕터 라벨(우상단, blue, bold) + 제목(좌상단, inkDeep, bold, 25pt) + 부제(steel, 13.5pt).
  **제목 아래 액센트 밑줄은 넣지 않는다** — AI가 만든 슬라이드 티가 나는 대표적 패턴이라 금지.
- 불릿은 파란 점(●) — 유니코드 불릿이 아닌 도형으로 그린다(이중 불릿 방지).
- 이미지 자리는 파란 점선 박스 + 🖼 아이콘 + 라벨 텍스트로 표시(실제 사진 생성 금지).
- 페이지 번호는 우하단, `stone` 색, `n / 총장수` 형식.

## 폰트 크기 (수업용 — 리포트보다 크게)
| 요소 | 크기 |
|---|---|
| 표지 제목 | 38pt |
| 슬라이드 제목 | 25pt |
| 부제 | 13.5pt |
| 본문 불릿 (2~3개) | 17pt |
| 본문 불릿 (4~5개) | 15.5pt |
| 본문 불릿 (6개+) | 13.5pt |
| 인용구 | 24pt |
| 마무리 제목 | 32pt |

## 절대 금지 (pptxgenjs 공통 규칙)
- hex 색상에 `#` 포함 금지 → 파일 손상
- `shadow` 객체 재사용 금지 → 매번 `makeShadow()` 함수로 새로 생성
- 제목 아래 컬러 바/스트라이프 장식 금지(닫는 슬라이드의 파란 발문 배너는 예외 — 기능적 강조 요소)
