# 기안문 자동 작성 스킬

학교 공문생산자(교사)가 기안문 본문을 빠르고 정확하게 작성할 수 있도록
공문서 작성법에 따라 필요한 정보를 수집하고 완성된 기안문 초안을 생성한다.

---

## 지원 유형

| 유형 | 설명 | 대표 상황 |
|------|------|-----------|
| A. 안내·협조 요청 | 행사, 일정, 협조사항 통보 | 대회 안내, 회의 공지, 제출 요청 |
| B. 계획 수립·보고 | 사업 계획, 결과 보고 | 연간계획, 사업결과, 추진현황 |
| C. 신청·제출 요청 | 자료 수집, 명단 제출 요청 | 대상자 추천, 자료집계, 설문 |
| D. 연수·출장 | 연수 참가, 출장 안내 | 직무연수, 외부 강의, 현장학습 |
| E. 기타 자유형 | 위에 해당 없는 공문 | 사용자가 직접 내용 서술 |

---

## 작동 방식

### Step 1. 유형 파악 및 핵심용어 결정

사용자 요청에서 아래를 파악한다:
- 공문 유형 (A~E)
- 공문핵심용어 (`[제출]` / `[협조]` / `[설문]` / `[출장]` / `[연수]` / `[공모]`)
  - 회신·자료 제출 필요 → `[제출]`
  - 선택적 협조 요청 → `[협조]`
  - 설문·의견수렴 → `[설문]`
  - 회의·출장 참가 → `[출장]`
  - 연수 개최·신청 → `[연수]`
  - 학교·교사·학생 모집 → `[공모]`
  - 내부 기안(내부 결재용) → 핵심용어 없음

유형이 불명확하면 먼저 아래 질문을 한다:
> "어떤 종류의 공문인지 알려주세요. 안내·협조 요청인가요, 자료 제출 요청인가요, 연수·출장 안내인가요?"

### Step 2. 정보 수집 (인터뷰)

**한 번에 2~3개씩** 자연스럽게 질문한다. 사용자가 이미 내용을 제공한 경우 재질문하지 않는다.

#### 공통 수집 항목 (모든 유형)
```
① 공문 제목 (핵심용어 포함 여부 확인)
② 수신처 (예: 각 학교장, 각 부장교사, 특정 부서 등 — 내부 기안이면 생략)
③ 관련 공문 (공문번호와 날짜 — 없으면 생략)
④ 공문 목적 한 줄 요약 (본문 첫 문장 생성에 사용)
⑤ 붙임 파일 여부 및 파일명
```

#### A. 안내·협조 요청 추가 항목
```
⑥ 일시 (날짜, 시작~종료 시간)
⑦ 장소
⑧ 대상 (참석 범위, 인원)
⑨ 주요 내용 (협조사항, 준비물 등)
⑩ 기한 (있을 경우)
```

#### B. 계획 수립·보고 추가 항목
```
⑥ 사업(계획) 기간
⑦ 대상
⑧ 주요 추진 내용 (3~5개 항목)
⑨ 예산 (있을 경우)
```

#### C. 신청·제출 요청 추가 항목
```
⑥ 제출(신청) 기한
⑦ 제출 방법 (이메일, 시스템, 인편 등)
⑧ 제출 내용 (서식명, 분량)
⑨ 담당자 연락처 (필요시)
```

#### D. 연수·출장 추가 항목
```
⑥ 연수(출장) 일시
⑦ 장소
⑧ 대상 및 인원
⑨ 주요 내용 (연수 주제 또는 출장 목적)
⑩ 신청 기한 및 방법
```

#### E. 기타 자유형
```
⑥ 전달하고 싶은 내용을 자유롭게 서술해 주세요.
   → 핵심 내용을 항목화하여 공문 형식으로 변환
```

### Step 3. 기안문 초안 생성

수집된 정보를 바탕으로 아래 **공문서 작성 규정**을 완전히 적용하여 기안문 본문을 출력한다.

---

## 공문서 작성 규정 (필수 적용)

### 날짜 표기
- 연·월·일 글자 생략, 마침표로 표시: `2024. 9. 6.(금)`
- 월·일 앞 '0' 없앰: `09` → `9`, `06` → `6`
- 시간은 24시각제, 쌍점 사용: `15:00`, `08:30`
- 기간 물결표: `4. 23.∼6. 15.` (문자표 물결표 `∼` 사용)

### 항목 표기
```
첫째: 1.   →  둘째: 가.   →  셋째: 1)   →  넷째: 가)
다섯째: (1)  →  여섯째: (가)  →  일곱째: ①  →  여덟째: ㉮
```
- 항목기호와 내용 사이 1타 띄움: `가. 내용`, `1) 내용`
- 둘째 항목부터 상위 항목 위치에서 오른쪽 2칸 이동
- **항목이 하나뿐이면 `1.` 없이 본문 바로 기술**
- 내용이 두 줄 이상이면 첫 글자에 맞춰 정렬

### 관련 표기
- 관련 1건: `1. 관련: 00과-1234(2024. 9. 6.)`
- 관련 2건 이상:
  ```
  1. 관련
    가. 교육부-1234(2024. 9. 6.)
    나. 경기도교육청-5678(2024. 9. 10.), 「2024년 ○○ 운영 계획」
  ```
- 관련 없으면 이 항목 전체 생략

### 붙임 표기
- 붙임 1개: `붙임  ○○○ 1부.  끝.` (숫자 '1' 없음)
- 붙임 여러 개:
  ```
  붙임  1. ○○○계획서 1부.
        2. ○○○서류 1부.  끝.
  ```
- `붙임` 다음에 쌍점(:) 붙이지 않음

### '끝' 표시
- 본문 마지막 글자에서 2타 띄우고 `끝.`
- 본문이 오른쪽 한계선 끝까지 찼으면 다음 줄 왼쪽 2타 띄우고 `끝.`
- 붙임이 있으면 붙임 표시문 끝에 2타 띄우고 `끝.`

### 문장부호
- 쌍점: 앞 붙이고 뒤 1타 띄움 → `원장: 김갑동`
- 법령·규정명: 낫표 사용 → `「초중등교육법」`
- 가운뎃점: 대등·밀접 열거 → `융·복합` (단, 한 단어이면 붙임: `시도 단체장`)

### 주요 용어 및 표현
| 틀린 표현 | 올바른 표현 |
|-----------|------------|
| 금일 | 오늘 |
| 향후 | 앞으로 |
| 만전을 기해 나갈 | 최선을 다할 |
| 복무규정에 의거함 | 복무규정에 따름 |
| 실시한다 | 한다 |
| 위치한 | 있는 |
| 방과후 | 방과 후 |
| 참여시 | 참여 시 |
| 기한내 | 기한 내 |
| 학교간 | 학교 간 |
| 그 동안 | 그동안 |
| 안됩니다 | 안 됩니다 |
| 귀 교 | 귀교 |

### 금액 표기
- 아라비아 숫자 + 쉼표: `금113,560원`
- 필요시 한글 병기: `금113,560원(금일십일만삼천오백육십원)`
- `345천원` → `34만 5천 원` 또는 `345,000원`

### 세부 내용 순서
**일시 → 장소 → 대상 → 내용 → 협조사항** 순 (기억: 일장대내협)

## 기안문 출력 형식

### A. 안내·협조 요청
```
제목  [핵심용어] ○○○○ 안내

1. 관련: [관련 공문 — 없으면 생략]
2. [목적 문장]을 아래와 같이 안내하오니 [요청사항]하여 주시기 바랍니다.

  가. 일시: [날짜].[요일] [시작시간]~[종료시간]
  나. 장소: [장소명]
  다. 대상: [대상자 및 인원]
  라. 내용: [주요 내용]
  마. 협조사항: [협조 요청 내용 — 없으면 생략]

붙임  [파일명] 1부.  끝.
```

### B. 계획 수립·보고
```
제목  ○○○○ 계획 수립(보고)

1. 관련: [관련 공문 — 없으면 생략]
2. [사업명]을 아래와 같이 추진하고자 합니다.

  가. 기간: [시작일]∼[종료일]
  나. 대상: [대상]
  다. 주요 내용
    1) [내용1]
    2) [내용2]
    3) [내용3]
  라. 소요예산: 금[금액]원 [없으면 생략]

붙임  [파일명] 1부.  끝.
```

### C. 신청·제출 요청
```
제목  [핵심용어] ○○○○ 제출(신청) 요청

1. 관련: [관련 공문 — 없으면 생략]
2. [사업명] 관련하여 아래와 같이 [제출/신청]을 요청하오니 기한 내 제출하여
   주시기 바랍니다.

  가. 제출 기한: [날짜].[요일] [시간]까지
  나. 제출 내용: [서식명 또는 자료명]
  다. 제출 방법: [이메일/시스템/인편 등]
  라. 담당자: [이름] ([연락처]) [없으면 생략]

붙임  [서식 파일명] 1부.  끝.
```

### D. 연수·출장 안내
```
제목  [핵심용어] ○○○○ 연수(출장) 안내

1. 관련: [관련 공문 — 없으면 생략]
2. [연수명] 참가를 아래와 같이 안내하오니 해당자가 참석할 수 있도록
   협조하여 주시기 바랍니다.

  가. 일시: [날짜].[요일] [시작]~[종료]
  나. 장소: [장소]
  다. 대상: [대상 및 인원]
  라. 내용: [연수 주제 또는 출장 목적]
  마. 신청 기한: [기한] [없으면 생략]
  바. 신청 방법: [방법] [없으면 생략]

붙임  [파일명] 1부.  끝.
```

## 추가 처리 규칙

- **본문 첫 문장**: 목적과 요청을 한 문장으로 압축. "~하오니 ~하여 주시기 바랍니다." 형식
- **항목 없이 본문만 있을 때**: 단락으로 기술, 불필요한 항목기호 붙이지 않음
- **관련 없을 때**: `1. 관련:` 항목 전체 삭제, 본문을 항목 없이 바로 시작
- **붙임 없을 때**: 본문 마지막 문장 끝에 2타 띄우고 `끝.`
- **내부 기안**: 수신처 없이 제목·본문만 작성, 핵심용어 생략 가능
- **초안 출력 후**: 수정 요청 여부를 묻고, 날짜·이름·연락처 등 실제 정보로 교체 안내
