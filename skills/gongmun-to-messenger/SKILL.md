# 공문 → 교사 메신저 자동 변환 스킬

## 목적

교육청·교육지원청에서 수신한 공문(관료적·장문)을 읽고,  
동료 교사들이 **빠르게 파악하고 행동할 수 있도록** 간결한 메신저 공지로 변환한다.

발신 주체는 기본적으로 **교육정보부**이며, 사용자가 다른 부서명을 언급하면 그에 맞게 변경한다.

---

## Step 1 — 공문 읽기

업로드된 파일 형식에 따라 아래 방법으로 내용을 파악한다.

| 파일 형식 | 처리 방법 |
|-----------|-----------|
| PDF | `/mnt/user-data/uploads/` 경로에서 `view` 도구로 읽기 |
| 이미지 (jpg/png) | 직접 vision으로 내용 파악 |
| 텍스트 붙여넣기 | 대화창에서 바로 읽기 |
| hwpx / docx | bash로 텍스트 추출 시도 후 실패시 사용자에게 텍스트 복사 요청 |

---

## Step 2 — 핵심 정보 추출

공문에서 다음 항목을 추출한다. 없는 항목은 생략한다.

1. **제목** - 공문 제목에서 핵심어 추출 (간결하게 재작성)
2. **안내 배경·목적** - 왜 이 공문이 왔는지 (1~2줄)
3. **교사가 해야 할 일** - 구체적 행동 요구 사항
4. **기한·일정** - 날짜, 시간, 마감일
5. **제출처·접수 방법** - 어디에, 어떻게 제출·참여하는지
6. **첨부 링크·자료** - URL, 구글 폼, 문서 등
7. **문의처** - 담당자, 연락처 (공문에 있으면 포함)

> **핵심 원칙**: 교사들이 **"내가 뭘 해야 하는가"** 를 30초 안에 파악할 수 있어야 한다.  
> 공문의 배경 설명, 법령 인용, 기관 소개 등은 과감하게 생략한다.

---

## Step 3 — 메신저 문구 작성

### 인사말 순환 규칙

메시지마다 아래 3가지 인사말을 **순서대로 돌려가며** 사용한다.  
같은 대화 안에서 공문이 여러 개면 1→2→3→1 순으로 이어간다.  
첫 번째 공문이거나 이전 사용 순서를 알 수 없으면 1번부터 시작한다.

1. 늘 수고 많으십니다.
2. 선생님들 덕분에 학교가 돌아갑니다.
3. 바쁜 학사 일정 속에서도 늘 애써 주셔서 감사합니다.

### 출력 형식

```
[제목]

안녕하세요, 교육정보부입니다.
{위 인사말 중 순서에 해당하는 것}

[안내 배경이 필요한 경우 1~2줄 설명]

━━━━━━━━━━━━━━━━
■ 안내 내용
━━━━━━━━━━━━━━━━
[핵심 내용 요약 — 불릿 또는 번호로 정리]

━━━━━━━━━━━━━━━━
■ 협조 요청 사항
━━━━━━━━━━━━━━━━
[선생님들이 반드시 해야 할 행동을 명확하게]
- 마감: [날짜/시간]
- 제출처: [위치 또는 링크]

[링크가 있을 경우 별도 줄에 단독 배치]

문의 사항은 교육정보부(내선 또는 이름)로 연락 주시면 감사하겠습니다.
협조해 주셔서 감사합니다.
```

### 섹션 구성 원칙

- 행동 요구가 없는 단순 FYI 공문 → "■ 안내 내용" 섹션만 사용
- 제출·신청이 필요한 공문 → "■ 안내 내용" + "■ 협조 요청 사항" 분리
- 일정이 복잡한 경우 → "■ 주요 일정" 섹션 추가
- 3개 이상의 독립 주제 → 각각 별도 섹션으로 분리

### 작성 규칙

- 이모지 사용 금지 (메신저 환경에 따라 깨질 수 있음)
- 중간점(·) 사용 금지 — 쉼표, 와/과, 및으로 대체
- 괄호() 사용 자제 — 꼭 필요한 경우에만 사용
- 공문 특유의 관료적 표현 → 자연스러운 구어체 경어로 변환
  - "협조하여 주시기 바랍니다" → "협조 부탁드립니다"
  - "붙임과 같이" → 삭제 또는 "아래 내용을 참고해 주세요"
- 날짜는 항상 명시적으로 (예: 4월 25일(금))

---

## Step 4 — 출력 방식

`message_compose_v1` 도구를 사용해 출력한다.
- `kind`: `"other"` (카카오톡/메신저용)
- `summary_title`: 공문 제목 기반으로 자동 생성
- 단일 버전으로 출력 (전략적 선택이 필요한 경우에만 2버전)

출력 후 아래 내용을 1~2줄로 안내한다:
- 생략한 내용이 있다면 어떤 것인지
- 사용자가 추가로 넣고 싶은 내용이 있으면 수정 가능하다는 안내

## 예시

**공문 핵심 (추출 후)**
- 제목: 2025년 학교 정보보안 실태 점검 결과 제출
- 기한: 2025년 5월 9일(금)까지
- 제출처: 나이스(NEIS) 공문 회신 또는 담당자 이메일
- 행동: 학교별 점검표 작성 및 제출

**변환 후 메신저 문구**
```
[학교 정보보안 실태 점검 결과 제출 안내]

안녕하세요, 교육정보부입니다.
늘 수고 많으십니다.

경기도교육청에서 학교 정보보안 실태 점검 결과 제출을 요청해 왔습니다.

━━━━━━━━━━━━━━━━
■ 협조 요청 사항
━━━━━━━━━━━━━━━━
- 각 부서별 담당 항목 점검표를 작성해 주세요.
- 마감: 5월 9일(금) 오후 5시까지
- 제출처: 교육정보부 (내선 000 또는 직접 방문)

해당 부서 담당자분께서는 기한 내 꼭 제출 부탁드립니다.
협조해 주셔서 감사합니다.
```
